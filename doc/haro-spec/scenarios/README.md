# haro 상세 사용자 시나리오

이 폴더는 haro를 처음 보는 사람이 “이 제품이 내 일에 어떻게 들어오는지”를 이야기로 이해할 수 있게 만든다.

기술 스펙 문서가 아니라 고객 성공 스토리에 가깝다.
각 시나리오는 한 사람 또는 한 팀이 업무 과부하를 겪다가 haro를 만나고, 처음에는 조심스럽게 써보다가, 점점 자기 업무 방식 안에 흡수하고, 마지막에는 주변에 추천할 정도로 신뢰하게 되는 흐름을 담는다.

## 읽는 법

각 문서는 다음 질문에 답해야 한다.

- 이 사람은 왜 지금 무너지고 있는가?
- haro를 알게 된 계기는 왜 자연스러운가?
- 처음 설정 과정은 비개발자에게 얼마나 쉬운가?
- 첫 번째 가치는 어느 순간 체감되는가?
- haro는 어떻게 사용자의 피드백을 기억하고 반복 업무를 스킬로 바꾸는가?
- 팀이나 사업에 완전히 통합되면 무엇이 달라지는가?
- 왜 이 사람이 haro의 팬이 되고 전도사가 되는가?

## 공통 흐름

모든 시나리오는 아래 구조를 따른다.

1. 무너지기 직전의 하루
2. haro를 알게 되는 순간
3. 처음 설정하는 과정
4. 첫 번째 가치 체감
5. 적응과 확장
6. 완전 통합
7. 해피 엔딩
8. 기능 매핑 박스

## 톤

이야기는 과장된 광고 문구가 아니라 실제 업무자의 언어로 쓴다.
haro가 모든 것을 마법처럼 해결하는 것이 아니라, 사용자의 피드백과 승인, 팀의 기준, 반복 학습을 통해 점점 더 정확해지는 흐름을 보여준다.
