# 마케팅 코워크 솔루션 아이디어 노트

## 1. 문제 정의

마케팅 팀은 보통 월 1억 원 안팎의 예산을 운영하면서 4명 내외의 팀으로 구성된다. 이 팀은 한 달에 약 100개 정도의 단위 태스크를 처리해야 한다.

현재 업무 시간은 대략 다음처럼 쓰인다.

| 구분 | 비중 | 주요 업무 |
| --- | ---: | --- |
| 데이터/운영 수작업 | 50% | 엑셀, CSV, 리포트 정리, 캠페인 성과 취합, 데이터 클렌징 |
| 반복 커뮤니케이션 | 30% | 이메일 초안, 팔로업, 협력사 확인, 내부 요청, 상태 공유 |
| 창의적 계획 | 20% | 캠페인 기획, 메시지 전략, 실험 설계, 크리에이티브 방향 |

핵심 문제는 마케팅 팀의 시간이 고부가가치 판단보다 반복 실행과 조율에 많이 묶여 있다는 점이다.

## 2. 제품 가설

Claude Code, MCP, Skills와 유사한 에이전트 실행환경을 클라우드화하면 마케팅 운영 업무 상당 부분을 팀 단위로 자동화할 수 있다.

가설은 다음과 같다.

| 업무 영역 | 자동화 접근 |
| --- | --- |
| 데이터/운영 수작업 | 에이전트가 파일을 이해하고, 필요한 코드를 생성/실행하여 정리, 분석, 리포트 생성 |
| 반복 커뮤니케이션 | 페르소나 에이전트가 이메일/메시지 초안 작성, 사람이 승인 또는 수정 |
| 창의적 계획 | 전문가 에이전트와 마케팅 스킬이 캠페인 전략, 실험안, 카피, 콘텐츠 방향 제안 |

즉, 단순한 마케팅 자동화 툴이 아니라 **마케팅 팀을 위한 클라우드형 AI 코워크 실행환경**을 만든다.

## 3. 현재 페인포인트

Claude Code류 도구는 강력하지만 기본적으로 로컬 중심이다.

- 개인 PC의 파일시스템에 묶인다.
- 개인별 세션과 컨텍스트가 분리된다.
- MCP, Skills, 권한, 실행환경이 사용자마다 다르게 구성된다.
- 팀 프로젝트의 공용 작업공간으로 쓰기 어렵다.
- 실행 결과물, 로그, 파일, 대화가 팀 단위 자산으로 남기 어렵다.

마케팅 팀이 필요한 것은 개인 비서보다 **공용 작업실**에 가깝다.

## 4. 만들고 싶은 형태

브라우저에서 접근 가능한 클라우드 워크스페이스를 제공한다.

사용자는 프로젝트별 공간에서 다음을 수행한다.

- 파일 업로드 및 관리
- 에이전트와 대화
- 코드 생성 및 샌드박스 실행
- 엑셀/CSV 분석
- 리포트와 대시보드 생성
- 이메일/슬랙/협력사 커뮤니케이션 초안 생성
- 결과물 미리보기 및 호스팅
- 팀원 간 공유와 이어받기

제품을 한 문장으로 표현하면 다음과 같다.

> Claude Code + MCP + Skills + 샌드박스 파일시스템 + 코드 실행 + 호스팅 + 팀 협업 + 마케팅 업무 템플릿을 클라우드에서 제공하는 코워크 플랫폼.

## 5. POC에서 확인할 질문

POC의 핵심 질문은 다음이다.

> Claude Code 같은 로컬 에이전트 개발환경을 클라우드의 팀 공용 실행환경으로 바꿀 수 있는가?

검증해야 할 하위 질문은 다음과 같다.

1. 클라우드 샌드박스에서 프로젝트별 파일 관리가 가능한가?
2. 에이전트가 안전하게 코드를 생성하고 실행할 수 있는가?
3. 실행 결과물을 팀원이 함께 보고 이어받을 수 있는가?
4. MCP와 Skills를 마케팅 업무용으로 미리 세팅할 수 있는가?
5. 결과물을 웹 앱, 리포트, 대시보드, 문서 등으로 배포하거나 호스팅할 수 있는가?
6. 개인 로컬 세션이 아니라 프로젝트 단위 공유 컨텍스트로 운영할 수 있는가?

## 6. 첫 POC 범위

처음에는 작고 선명한 루프를 만든다.

1. 마케팅 프로젝트 워크스페이스 생성
2. CSV 또는 엑셀 파일 업로드
3. 에이전트가 데이터 구조 파악
4. Python 또는 TypeScript 코드 생성
5. 샌드박스에서 코드 실행
6. 정리된 데이터, 차트, 요약 리포트 생성
7. 이메일 또는 슬랙 공유문 초안 생성
8. 결과물을 웹 페이지로 미리보기 또는 배포
9. 모든 파일, 실행 로그, 대화가 프로젝트 공간에 남음
