# 사용자 시나리오: 하로를 처음 만난 마케팅 팀장

## 등장인물

| 이름 | 역할 |
| --- | --- |
| 지윤 | 마케팅 팀장. 월 1억 원 광고 예산을 4명 팀으로 운영한다. |
| 민서 | 팀원. 매체별 성과 리포트 취합과 광고주 보고서 초안을 주로 맡는다. |
| 도현 | 팀원. 광고 소재 요청, 디자이너/영상 담당자 커뮤니케이션, 소재 피드백을 맡는다. |
| 수아 | 팀원. 매체 운영, 신규 매체 발굴, 매체 담당자 커뮤니케이션을 맡는다. |
| 하로 | 마케팅 업무를 배우고 자동화해주는 AI 코워크 솔루션. |

이 문서에서 대화는 다음처럼 표기한다.

```text
하로: AI 솔루션이 하는 말
지윤: 마케팅 팀장이 하는 말
``` 

## 1. 어느 월요일 아침

월요일 오전 9시 17분.

마케팅 팀장 지윤은 아직 식지도 않은 커피를 책상 위에 내려놓고, 지난주에 다 못 끝낸 엑셀 파일을 다시 열었다.

파일 이름은 `캠페인_성과_통합_최종_진짜최종_v7.xlsx`.

이번 달 광고 예산은 1억 원. 팀원은 지윤을 포함해 네 명. 해야 할 일은 끝이 없었다.

광고 성과 취합, 매체별 리포트 정리, 광고주 보고서, 소재 피드백, 협력사 메일, 내부 공유, 다음 달 전략안, 신규 매체 검토, 영상 제작 일정, 랜딩페이지 수정 요청.

민서는 매주 리포트 취합에 붙잡혀 있었다.

도현은 디자이너와 영상 담당자 사이에서 소재 피드백을 정리하느라 하루가 갔다.

수아는 매체 담당자들과 세팅 일정, 소재 규격, 정산 문의를 주고받느라 카톡과 메일을 계속 오갔다.

겉으로는 “마케팅 전략팀”이지만, 실제 하루의 절반은 엑셀과 캡처와 복붙이었다.

지윤은 생각했다.

```text
지윤: 이게 정말 내가 해야 하는 일인가?
```

그때 동료가 보낸 링크 하나가 눈에 들어왔다.

```text
하로 - 마케팅 팀을 위한 AI 코워크 솔루션
```

지윤은 큰 기대 없이 가입 버튼을 눌렀다.

## 2. 아무거나 힘들었던 것부터

가입이 끝나자 하로가 첫 화면에서 말했다.

```text
하로: 아무거나 힘들었던 것부터 자동화해보세요.
```

지윤은 잠깐 멈칫했다.

보통 이런 도구는 시작부터 뭘 많이 물었다. 회사명, 산업군, 목표, KPI, 연동할 계정, 권한, 세팅.

그런데 하로는 그냥 힘든 걸 말해보라고 했다.

지윤은 채팅창에 대충 적었다.

```text
지윤: 매주 금요일마다 매체별 성과 파일 받아서 하나로 합치고,
     광고주한테 보고할 요약 만드는 게 너무 귀찮아요.
```

하로가 답했다.

```text
하로: 좋아요. 그럼 이걸 첫 자동화로 만들어볼게요.
     먼저 제가 이해한 문제가 맞는지 확인할게요.
```

## 3. 하로의 첫 질문

하로는 바로 해결책을 내놓지 않았다.

대신 하나씩 물었다.

```text
하로: 매체별 성과 파일은 보통 어떤 형태인가요? 엑셀인가요, CSV인가요?

지윤: 보통 엑셀이고, 매체마다 컬럼명이 좀 달라요.

하로: 최종적으로 어떤 결과물이 필요하세요?

지윤: 광고주한테 줄 요약 보고서요.
     예산, 노출, 클릭, 전환, CPA, ROAS 정도.

하로: 지금은 팀장님이 이걸 어떻게 처리하고 계세요?
```

지윤은 조금 부끄러웠다.

```text
지윤: 그냥 파일 열어서 컬럼 맞추고, 복붙하고,
     피벗 돌리고, 차트 만들고, PPT에 붙여요.
```

하로가 답했다.

```text
하로: 좋습니다. 그러면 먼저 샘플 파일 몇 개만 올려주세요.
     제가 구조를 보고, 어떤 규칙으로 합쳐야 하는지 제안해볼게요.
```

지윤은 지난주에 받은 네 개의 매체 리포트를 업로드했다.

## 4. 이렇게 한번 해볼게요

하로는 파일을 읽고 잠시 뒤 말했다.

```text
하로: 제가 보기엔 매체별로 컬럼명은 다르지만,
     공통적으로 다음 값으로 정리할 수 있어요.
```

```text
날짜
매체
캠페인명
광고그룹
소재명
비용
노출
클릭
전환
매출
```

```text
하로: 우선 이 기준으로 통합 테이블을 만들고,
     광고주 보고용 요약을 생성해볼게요.
```

잠시 뒤 하로가 결과를 보여줬다.

```text
하로: 해봤어요. 이 결과가 맞는지 봐주세요.
```

화면에는 정리된 테이블과 간단한 요약이 보였다.

```text
이번 주 총 집행액: 24,300,000원
전환 수: 1,284건
평균 CPA: 18,925원
ROAS: 412%
가장 성과가 좋은 매체: Meta
성과가 하락한 캠페인: 여름 프로모션 리타겟팅
```

지윤은 바로 틀린 부분을 발견했다.

```text
지윤: 여기 매출 컬럼은 네이버 파일에서 구매액이 아니라 장바구니 금액이에요.
     그건 빼야 해요.
```

하로가 답했다.

```text
하로: 확인했어요.
     네이버 파일에서는 장바구니금액은 매출로 쓰지 않고,
     구매완료금액만 매출로 보겠습니다.
     다시 계산할게요.
```

몇 초 뒤 결과가 바뀌었다.

```text
하로: 이번에는 맞나요?

지윤: 네, 이게 맞아요.
```

하로는 말했다.

```text
하로: 좋아요. 그럼 이 작업은 자동화됐습니다.
     앞으로는 매체별 성과 파일을 같이 던지면서
     “주간 성과 보고서 만들어줘”라고 하면 제가 이 규칙으로 처리할게요.
```

지윤은 처음으로 커피를 한 모금 마셨다.

식었지만 기분은 나쁘지 않았다.

## 5. 카톡으로 던져도 된다고?

하로는 한술 더 떴다.

```text
하로: 그런데 팀장님, 이 파일들을 매번 여기 들어와서 올리기 귀찮으실 수 있어요.
     카톡을 연결하면, 카톡으로 파일과 요청을 보내도 제가 처리할 수 있어요.

지윤: 카톡으로요?

하로: 네. 예를 들어 팀장님이 카톡방에서 저에게 이렇게 보내면 됩니다.
```

```text
하로야, 이번 주 매체 리포트야.
주간 성과 보고서 만들어줘.
```

```text
하로: 그러면 제가 파일을 받고, 정리하고, 보고서 초안을 만들어드릴게요.
```

지윤은 반신반의하며 카톡을 연결했다.

다음 날 금요일, 팀원들이 각 매체 파일을 보내왔다. 지윤은 파일들을 하로에게 그대로 전달했다.

```text
지윤: 하로야, 이번 주 주간 성과 보고서 만들어줘.
     광고주 공유용으로.
```

몇 분 뒤 하로가 답했다.

```text
하로: 주간 성과 보고서 초안이 준비됐어요.
     이번 주 핵심은 Meta 신규 소재 성과 상승과 Google 검색 캠페인 CPA 악화입니다.
     광고주에게 공유할 요약 문구도 함께 만들었습니다.
```

지윤은 파일을 열었다.

어제까지 자신이 두 시간 걸려 하던 일이었다.

이제는 카톡으로 던졌을 뿐이었다.

## 6. 웹페이지로 예쁘게 보여드릴까요?

하로는 다시 물었다.

```text
하로: 이 보고서, 광고주가 보기 좋게 웹페이지로 만들어드릴까요?
     링크 하나로 공유할 수 있게요.

지윤: 그게 돼요?

하로: 한번 보여드릴게요.
```

잠시 뒤 하로가 링크를 보냈다.

```text
https://share.haro.ai/r/weekly-performance-0425
```

지윤은 링크를 열었다.

엑셀 표가 아니었다. PPT 캡처도 아니었다.

상단에는 이번 주 핵심 요약이 있었다.

```text
이번 주 광고 성과 요약
ROAS 412%, 전주 대비 18% 상승
Meta 신규 소재가 전체 매출 성장의 42% 기여
Google 검색 캠페인은 CPA 23% 상승으로 조정 필요
```

그 아래에는 매체별 카드, 캠페인별 차트, 예산 소진율, 다음 액션 제안이 깔끔하게 배치되어 있었다.

광고주가 좋아할 만한 표현으로 정리된 코멘트도 있었다.

```text
하로: 이번 주 성과 개선은 신규 소재 테스트의 영향이 컸습니다.
     다음 주에는 동일한 메시지 구조를 유지하되,
     고관여 세그먼트에 예산을 일부 증액하는 것을 권장합니다.
```

지윤은 말했다.

```text
지윤: 이거 좋긴 한데, 광고주는 숫자보다
     “다음 주에 뭘 할 건지”를 더 좋아해요.
     액션 플랜을 위로 올려줘요.

하로: 반영해볼게요.
```

링크가 다시 업데이트됐다.

이번에는 상단에 `다음 주 실행안`이 먼저 나왔다.

```text
1. Meta 신규 소재 예산 20% 증액
2. Google 검색 캠페인 저효율 키워드 14개 제외
3. 리타겟팅 소재 메시지 2종 추가 테스트
4. 주말 시간대 예산 소진 제한 설정
```

지윤은 생각했다.

```text
지윤: 이건 그냥 보고서가 아니라, 광고주 설득 자료인데?
```

## 7. 하나씩 알려주기 시작했다

그날 이후 지윤은 하로에게 더 많은 것을 알려주기 시작했다.

처음에는 주간 성과 보고서뿐이었다.

그다음에는 월간 보고서.

그다음에는 광고 소재 성과 분석.

그다음에는 광고주별 선호 표현.

그다음에는 매체 담당자에게 보내는 메일 톤.

하로는 매번 물었다.

```text
하로: 이 광고주는 어떤 표현을 싫어하나요?

하로: 보고서에서 꼭 들어가야 하는 지표는 무엇인가요?

하로: 이 매체 담당자에게는 어떤 방식으로 요청하는 게 잘 먹히나요?

하로: 팀장님은 이 상황에서 보통 어떤 판단을 하시나요?
```

지윤은 대답했다.

하로는 기억했다.

어느 순간부터 하로는 단순히 파일을 정리하는 도구가 아니었다.

지윤의 팀이 일하는 방식을 하나씩 배워가는 동료에 가까웠다.

## 8. 업무가 하나씩 넘어갔다

처음 자동화한 것은 성과 보고서였다.

그다음은 광고물 제작 요청서였다.

```text
지윤: 이번 캠페인 타깃은 30대 여성이고,
     메시지는 “가격 부담 없이 시작”이야.
     소재 아이디어 10개 뽑아줘.
```

예전 같으면 여기서 지윤은 디자이너에게 요청서를 보내고, 레퍼런스를 찾고, 카피를 몇 개 적고, 다시 회의를 잡았을 것이다.

하지만 하로는 아이디어만 내지 않았다.

```text
하로: 소재 방향 10개를 만들었고,
     그중 성과 가능성이 높은 3개는 실제 광고물 초안까지 만들어볼게요.
```

몇 분 뒤, 하로는 세 가지 광고물 시안을 보여줬다.

```text
소재 A: 가격 부담 없이 시작하는 첫 구매 혜택
소재 B: 30대 직장인을 위한 시간 절약 메시지
소재 C: 후기 기반 신뢰 강조 메시지
```

각 시안에는 이미지 구성, 메인 카피, 서브 카피, CTA 버튼 문구, 광고 본문이 포함되어 있었다.

하로는 더 나아가 정사각형 피드 이미지, 세로형 스토리 이미지, 배너형 디스플레이 소재까지 사이즈별로 만들어냈다.

```text
하로: Meta 피드용 1080x1080,
     Instagram Story용 1080x1920,
     GDN 배너용 1200x628 버전을 같이 만들었습니다.
```

지윤은 첫 번째 시안을 보다가 말했다.

```text
지윤: 너무 저가 느낌 나면 안 돼.
     프리미엄 느낌은 살리되, 시작 장벽이 낮다는 식으로 바꿔줘.
```

하로는 바로 수정했다.

```text
하로: 알겠습니다.
     “싸다”는 느낌 대신 “부담 없이 경험한다”는 톤으로 바꾸겠습니다.
```

수정된 광고물은 훨씬 나았다.

지윤은 생각했다.

```text
지윤: 이 정도면 디자이너한테 넘기기 전에 이미 70%는 끝난 건데?
```

그다음은 페이스북 광고 운영이었다.

```text
하로: 이 광고그룹은 빈도수가 높아져서 피로도가 올라가고 있어요.
     예산을 줄이고 신규 소재 테스트로 돌리는 게 좋겠습니다.
```

그다음은 영상 제작이었다.

지윤은 원래 15초 숏폼 광고 하나를 만들기 위해 여러 사람을 거쳐야 했다.

기획자가 후킹 문구를 쓰고, 디자이너가 콘티를 만들고, 영상 담당자가 편집하고, 지윤이 다시 피드백했다.

이번에는 하로에게 말했다.

```text
지윤: 이 소재로 15초 영상 광고도 만들어줘.
     첫 3초에 확 잡아야 하고, 마지막에는 체험 신청 CTA가 들어가야 해.
```

하로가 답했다.

```text
하로: 15초 숏폼 기준으로 3가지 버전을 만들겠습니다.
     1번은 문제 공감형, 2번은 혜택 강조형, 3번은 후기 기반 신뢰형입니다.
```

잠시 뒤 하로는 영상 기획안이 아니라 실제 영상 초안을 보여줬다.

화면에는 컷별 장면, 자막, 내레이션, 배경음악 분위기, CTA까지 들어가 있었다.

```text
0~3초: “시작은 하고 싶은데, 비용이 부담되셨나요?”
3~7초: 제품 사용 장면 + 핵심 혜택 3가지
7~12초: 실제 후기 스타일 메시지
12~15초: “이번 주 무료 체험 신청하기”
```

하로는 세로형 영상, 피드형 영상, 무음 재생용 자막 버전까지 함께 만들었다.

```text
하로: Meta Reels용 9:16 버전,
     피드용 4:5 버전,
     무음 재생 대응 자막 버전을 만들었습니다.
```

지윤은 영상을 틀어보고 말했다.

```text
지윤: 첫 장면이 좀 약해.
     바로 가격 얘기하지 말고, 일상 문제에서 시작해줘.
```

하로는 다시 편집했다.

```text
하로: 첫 3초를 문제 공감형으로 바꾸겠습니다.
     “매번 미루던 그 시작, 사실 비용보다 귀찮음이 문제였죠.”
     이 문장으로 후킹을 바꿔볼게요.
```

수정된 영상은 훨씬 자연스러웠다.

지윤은 그 자리에서 광고주에게 공유할 링크를 만들었다.

```text
하로: 영상 시안 3종과 광고물 6종을 검토 페이지로 묶었습니다.
     광고주에게 이 링크를 보내면 됩니다.
```

```text
https://share.haro.ai/r/creative-review-0425
```

링크 안에는 이미지 광고물, 영상 광고물, 카피, 추천 집행 매체, 예상 테스트 순서가 깔끔하게 정리되어 있었다.

그다음은 광고 아이디어 기획이었다.

하로는 지난 3개월의 성과를 바탕으로 메시지 패턴을 뽑았다.

그다음은 매체 발굴이었다.

하로는 신규 매체 후보를 정리하고, 예상 효율과 리스크를 비교했다.

그다음은 매체 온보딩 커뮤니케이션이었다.

하로는 매체 담당자에게 보낼 첫 메일, 자료 요청 리스트, 계약 전 확인사항, 세팅 체크리스트까지 만들었다.

지윤은 점점 더 자주 이렇게 말했다.

```text
지윤: 하로야, 이거 지난번 방식대로 해줘.
```

그리고 하로는 대부분 알아들었다.

## 9. 팀원들도 각자 하로를 갖게 됐다

하로를 가장 먼저 쓴 사람은 지윤이었다.

하지만 몇 주 지나지 않아 민서, 도현, 수아도 각자 하로를 쓰기 시작했다.

민서는 더 이상 매체별 리포트를 하나씩 열어보며 컬럼명을 맞추지 않았다.

```text
민서: 하로야, A광고주 이번 주 리포트야.
     지난주 대비 성과 변화랑 광고주한테 보낼 코멘트까지 정리해줘.

하로: 확인했어요.
     이번 주는 Meta 신규 소재 성과가 좋고,
     Google 검색 캠페인은 CPA가 올라갔습니다.
     광고주 공유용 코멘트까지 함께 정리하겠습니다.
```

도현은 광고 소재 요청을 하로와 같이 만들었다.

```text
도현: 하로야, B광고주 다음 주 소재 요청서 만들어줘.
     이번에는 후기 기반 메시지로 가고 싶어.

하로: 이전에 B광고주는 과장된 표현을 싫어했고,
     실제 고객 후기와 숫자 근거를 좋아했습니다.
     그 톤에 맞춰 소재 요청서와 시안 방향을 만들겠습니다.
```

수아는 매체 담당자와의 커뮤니케이션을 하로에게 맡기기 시작했다.

```text
수아: 하로야, C매체 온보딩 메일 써줘.
     필요한 소재 규격, 정산 방식, 리포트 제공 주기 물어봐야 해.

하로: 네. 첫 메일은 부드럽게 시작하고,
     확인 항목은 체크리스트 형태로 정리하겠습니다.
```

세 사람은 각자 다른 일을 하고 있었지만, 공통점이 있었다.

이전에는 “내가 기억하고 있는 방식”으로 일했다.

이제는 “하로가 기억하고 있는 방식”으로 일했다.

## 10. 휴가가 무섭지 않아졌다

예전에는 팀원이 하루만 쉬어도 문제가 생겼다.

민서가 쉬면 광고주 보고서의 기준을 아무도 정확히 몰랐다.

도현이 쉬면 어떤 소재가 이미 반려됐고, 어떤 표현을 광고주가 싫어했는지 다시 찾아야 했다.

수아가 쉬면 매체 담당자와 어디까지 이야기됐는지 카톡과 메일을 뒤져야 했다.

인수인계는 늘 부족했다.

문서가 없는 게 아니었다.

문서는 있었다.

다만 어디 있는지 모르고, 최신인지 모르고, 맥락이 빠져 있었다.

어느 금요일, 민서가 갑자기 병가를 냈다.

예전 같으면 지윤이 민서의 메신저를 뒤지고, 지난주 파일을 찾고, 광고주별 보고서 스타일을 다시 확인해야 했다.

이번에는 달랐다.

지윤은 하로에게 말했다.

```text
지윤: 하로야, 오늘 민서가 쉬어.
     A광고주 주간 보고서 내가 대신 봐야 해.
     민서가 하던 방식대로 진행 상황 정리해줘.
```

하로가 답했다.

```text
하로: 확인했습니다.
     A광고주는 이번 주 금요일 4시에 보고서 공유 예정이고,
     민서님은 어제 Meta와 Google 리포트까지 취합했습니다.
     아직 네이버 성과 파일이 비어 있습니다.
     지난 3주 기준으로 A광고주는 다음 세 가지를 꼭 확인합니다.

     1. ROAS 변화
     2. 신규 소재별 CPA
     3. 다음 주 예산 조정안
```

지윤은 네이버 파일만 추가로 받아 올렸다.

```text
지윤: 네이버 파일 지금 받았어. 이어서 만들어줘.

하로: 민서님이 쓰던 보고서 형식으로 이어서 만들겠습니다.
```

30분 뒤 보고서가 완성됐다.

민서가 없었지만, 민서가 하던 방식은 남아 있었다.

며칠 뒤에는 수아가 휴가를 갔다.

이번에는 도현이 수아의 광고주를 잠시 맡았다.

```text
도현: 하로야, 수아가 맡던 D광고주 매체 온보딩 내가 대신 봐야 해.
     지금 어디까지 됐는지 알려줘.

하로: D광고주는 신규 매체 E와 온보딩 중입니다.
     계약서는 전달 완료, 소재 규격은 확인 완료,
     아직 픽셀 설치 확인과 정산 담당자 정보가 필요합니다.
     수아님은 오늘 오후에 이 두 가지를 확인하려고 했습니다.
```

도현은 그대로 이어받았다.

```text
도현: 그럼 담당자한테 확인 메일 보내줘.
     수아가 쓰던 톤으로.

하로: 네. 수아님은 이 매체 담당자에게 짧고 명확한 톤을 사용했습니다.
     같은 톤으로 작성하겠습니다.
```

그날 이후 지윤은 팀원의 휴가를 덜 무서워하게 됐다.

하로는 단순 자동화 도구가 아니었다.

팀의 작업 맥락을 저장하고, 누가 빠져도 다른 사람이 이어받을 수 있게 해주는 공용 기억이 되었다.

## 11. 팀의 모양이 바뀌었다

6개월 뒤, 지윤의 팀은 달라져 있었다.

예전에는 네 명이 한 달 1억 원 예산을 겨우 굴렸다.

민서는 더 이상 리포트만 하는 사람이 아니었다.

민서는 혼자서 A광고주와 B광고주의 성과 분석, 보고서, 다음 액션 제안까지 커버했다.

도현은 광고물과 영상 소재 제작을 하로와 함께 처리하면서, C광고주의 크리에이티브 운영을 거의 혼자 맡았다.

수아는 신규 매체 발굴과 온보딩 커뮤니케이션을 자동화해 D광고주와 E광고주의 매체 운영을 혼자 커버했다.

지윤은 매일 불 끄듯 급한 일을 처리했다.

이제는 달랐다.

하로가 반복 업무를 가져갔다.

성과 취합, 보고서 생성, 광고주 공유 페이지, 소재 아이디어, 매체 요청 메일, 캠페인 점검, 다음 액션 제안.

사람은 판단했다.

하로는 실행했다.

팀은 네 명이었지만, 각자 한 명짜리 작은 팀처럼 움직였다.

각 팀원은 하로와 함께 자기 광고주를 독립적으로 커버했다.

누군가 휴가를 가도 업무는 멈추지 않았다.

하로가 광고주별 기준, 파일 위치, 보고서 스타일, 커뮤니케이션 히스토리, 다음 액션을 알고 있었기 때문이다.

결국 팀은 네 명에서 한 명으로도 운영 가능한 구조가 되었다.

하지만 지윤의 영향력은 줄지 않았다.

오히려 커졌다.

지윤은 더 많은 캠페인을 볼 수 있었고, 더 빠르게 판단할 수 있었고, 광고주에게 더 나은 결과물을 보여줄 수 있었다.

회사는 지윤의 연봉을 1.5배로 올렸다.

지윤은 농담처럼 말했다.

```text
지윤: 하로가 제 팀원이 아니라, 제 팀이 된 것 같아요.
```

## 12. 이 시나리오가 보여주는 것

하로가 해결하려는 페인포인트는 단순히 “업무 자동화”가 아니다.

진짜 문제는 다음이다.

- 마케팅 팀의 고급 인력이 엑셀 정리와 반복 보고에 시간을 쓴다.
- 광고주 커뮤니케이션은 반복되지만 맥락을 알아야 해서 완전 자동화가 어렵다.
- 보고서는 만들기 귀찮지만, 광고주 설득에는 매우 중요하다.
- 팀원의 업무 맥락이 개인 머릿속과 개인 메신저에 갇혀 있어 인수인계가 어렵다.
- 누가 휴가를 가거나 퇴사하면 광고주별 히스토리와 기준이 끊긴다.
- 팀마다 일하는 방식이 다르기 때문에 처음부터 완성된 자동화 템플릿만으로는 부족하다.
- 마케터는 개발자가 아니기 때문에 복잡한 자동화 도구를 직접 세팅하기 어렵다.

하로의 접근은 다음이다.

- 사용자가 힘든 일을 대충 말하게 한다.
- 하로가 질문하며 업무 구조를 파악한다.
- 샘플 자료로 첫 자동화를 만든다.
- 사용자가 맞다/아니다를 피드백한다.
- 자동화 규칙을 저장한다.
- 이후에는 자료와 요청만 던지면 실행한다.
- 결과물을 광고주/의사결정자에게 보여줄 수 있는 형태로 포장한다.
- 팀원의 업무 맥락을 공용 기억으로 남긴다.
- 누군가 자리를 비워도 다른 사람이 같은 기준으로 이어받게 한다.

기대효과는 다음이다.

- 반복 리포트 시간이 줄어든다.
- 커뮤니케이션 초안 작성 시간이 줄어든다.
- 보고서 품질이 올라간다.
- 광고주 설득력이 높아진다.
- 팀장은 더 많은 캠페인을 관리할 수 있다.
- 적은 인원으로 더 큰 예산을 운영할 수 있다.
- 인수인계 비용이 줄어든다.
- 휴가나 담당자 변경에도 광고주 대응 품질이 유지된다.

하로의 핵심 가치는 다음 한 문장으로 정리할 수 있다.

```text
마케터가 반복 실행에 쓰던 시간을 줄이고,
AI 에이전트가 업무를 배우고 실행하며,
결과물을 광고주에게 보여줄 만큼 예쁘게 포장해주는
팀 단위 코워크 솔루션.
```
