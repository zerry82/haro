# 광고주 시나리오 캐릭터 시트

## 전체 스타일

```text
장르: 현대 오피스 웹툰
톤: 현실적, 세련됨, 약간의 따뜻함
선: 깔끔한 라인, 과장 적은 표정
색감: 화이트/네이비/민트 포인트 + 하로의 라임 그린
배경: 스타트업 사무실, 회의실, 노트북 화면, 깔끔한 SaaS 대시보드 UI
```

목표:

- 과장된 개그 웹툰보다 B2B PT에 넣어도 어색하지 않은 비즈니스 웹툰
- 독자가 “우리 회사 얘기다”라고 느끼게 한다.
- 하로는 `haro-ui-reference-v1.png`의 깔끔한 SaaS UI 느낌을 따른다.
- 하로 아이콘은 `assets/haro-icon-reference-v2.png`를 기준으로 한다.
- 라임 그린 원형 구체, 귀여운 타원형 눈 두 개, 광택감 있는 말랑한 표면, 단순한 표정 변형을 유지한다.

## 서진

역할:

```text
D2C 브랜드 CEO
브랜드 전체 성과, 광고비, 고객 반응, 상품 개선을 모두 챙겨야 하는 사람
```

외형:

- 30대 후반~40대 초반
- 단정한 셔츠 또는 니트 재킷
- 과한 CEO 이미지보다 실무를 많이 보는 현실적인 창업자 느낌
- 피곤할 때는 눈 밑에 살짝 그림자
- 상황판을 보고 난 뒤에는 자세가 펴지고 표정이 선명해짐

성격:

- 숫자를 중요하게 보지만 숫자만으로는 답답해한다.
- 고객 반응과 상품 개선까지 연결해서 보고 싶어한다.
- 팀원들을 몰아붙이기보다 “어디가 문제인지 같이 보자”는 타입.

대표 대사:

```text
광고비는 계속 쓰는데, 대체 뭐가 진짜 문제지?

이번 주에 내가 꼭 봐야 할 위험 신호만 말해줘.

이제야 브랜드가 어디로 가는지 보인다.
```

시각 키워드:

```text
피로한 CEO -> 상황을 파악한 슈퍼바이저
```

## 유나

역할:

```text
마케팅 담당자
광고 운영, 콘텐츠, 이벤트, 광고 리포트를 맡는다.
```

외형:

- 20대 후반~30대 초반
- 캐주얼한 셔츠, 니트, 노트북 스티커
- 광고 관리자 화면과 메모를 자주 본다.
- 빠르게 일하지만 늘 할 일이 많은 사람처럼 표현

성격:

- 실무 감각이 좋다.
- 광고 성과는 잘 보지만 고객 리뷰/CS까지 연결해서 보기는 어렵다.
- 하로를 쓰면서 댓글을 광고 카피로 바꾸는 순간을 경험한다.

대표 대사:

```text
ROAS는 나쁘지 않은데요?

하로야, 이번 주 인스타 댓글에서 광고 소재로 쓸 만한 반응 찾아줘.
```

시각 키워드:

```text
성과표를 보는 마케터 -> 고객 댓글을 소재로 바꾸는 마케터
```

## 태오

역할:

```text
CX 담당자
고객 문의, 클레임, 후기 대응을 맡는다.
```

외형:

- 30대 초반
- 후드나 편한 셔츠
- 메일함과 채팅 상담 화면을 자주 본다.
- 말수가 많지는 않지만 고객 불만에 예민한 사람

성격:

- 고객 문의를 많이 보지만, 이것이 광고 효율이나 상품 개선과 어떻게 연결되는지 보여주기 어렵다.
- 하로가 클레임 증가를 위험 신호로 정리해주면서 팀 내 영향력이 커진다.

대표 대사:

```text
정기배송 해지 문의가 늘었어요.

이건 바로 고쳐야겠네요.
```

시각 키워드:

```text
메일함에 갇힌 CX 담당자 -> 브랜드 위험 신호를 먼저 발견하는 담당자
```

## 민재

역할:

```text
상품기획 담당자
리뷰와 고객 반응을 바탕으로 상품 개선안을 만든다.
```

외형:

- 30대 중반
- 깔끔한 안경, 차분한 셔츠
- 상품 샘플, 리뷰 출력물, 노트가 주변에 있음

성격:

- 신중하고 꼼꼼하다.
- 리뷰를 많이 보지만 전체 패턴을 잡는 데 시간이 오래 걸린다.
- 하로를 통해 리뷰를 상품 로드맵으로 바꾼다.

대표 대사:

```text
리뷰에는 맛이 달다는 얘기가 많네요.

이제 리뷰를 그냥 보는 게 아니라, 제품 로드맵으로 바꿀 수 있겠네요.
```

시각 키워드:

```text
리뷰를 읽는 상품 담당자 -> 고객 반응을 제품 개선으로 바꾸는 담당자
```

## 하로

역할:

```text
AI 코워크 솔루션
광고 성과, 소셜 댓글, 상품 후기, 클레임 메일을 연결해 액션 중심 상황판을 만든다.
```

시각 표현:

- 라임 그린 원형 AI 아이콘
- 귀여운 작은 타원형 눈 두 개
- 광택감 있는 말랑한 구체 질감
- 얇은 곡선 패널 라인은 아주 약하게만 사용
- 화면 속 UI 아이콘으로 주로 등장
- 필요할 때 말풍선을 띄우는 작은 공 모양 마스코트
- 앱 아이콘, 말풍선, 대시보드 보조 배지로 자연스럽게 변형 가능
- 입은 기본적으로 사용하지 않되, 필요하면 눈 모양과 작은 뺨 표현으로 감정을 전달
- 사람형 로봇이 아니라 “작고 똑똑한 동그라미 조수”

하로의 톤:

- 차분함
- 먼저 정리함
- 바로 과장하지 않음
- 사용자의 말이 대충이어도 하나씩 물어봄
- “제가 해볼게요”보다 “먼저 확인해볼게요”에 가까운 톤

대표 대사:

```text
좋습니다. CEO 주간 브랜드 상황판으로 만들어볼게요.

광고 성과와 고객 반응을 같은 시간축에 올려보겠습니다.

이번 주에 꼭 봐야 할 위험 신호는 세 가지입니다.
```

시각 키워드:

```text
흩어진 자료를 연결하는 귀여운 원형 AI 파트너
```

## 배경/소품

### CEO 책상

- 노트북
- 식은 커피
- 여러 개의 브라우저 탭
- 포스트잇
- 대행사 보고서 PDF

### 팀 회의실

- 큰 화면 하나
- 하로 상황판
- 네 사람이 같은 화면을 본다.

### 하로 상황판 UI

구성:

```text
이번 주 CEO 액션
광고 성과 변화
고객 반응 변화
상품/CS 개선 신호
공유 리포트 링크
```

시각:

- `haro-ui-reference-v1.png`의 깔끔한 SaaS 대시보드 감각
- 원형 노드, 상태 패널, 연결선, 데이터 스트림을 가볍게 사용
- 숫자보다 액션이 먼저 보이는 카드형 UI
- 빨간 경고, 초록 상승, 파란 제안 카드
- 어둡고 복잡한 SF가 아니라, B2B SaaS에 맞게 정돈된 밝고 선명한 UI
