# 광고주 시나리오 웹툰 원고

## 제목

**광고비는 타고 있는데, 아무도 이유를 모른다**

## 제작 기준

- 총 18페이지
- 스토리보드 1컷 = 웹툰 1페이지
- 각 페이지는 세로형 단일 장면
- 한글 말풍선과 내레이션은 이미지 안에 직접 삽입
- 하로 UI는 `assets/haro-ui-reference-v1.png` 기준
- 하로 아이콘은 `assets/haro-icon-reference-v2.png` 기준

## 페이지 1. 숫자가 이상하다

이미지 파일:

```text
assets/webtoon-page-01-text.png
```

장면:

월요일 아침. 서진이 사무실에 가장 먼저 도착해 노트북을 본다. 주간 매출 그래프는 아래로 꺾여 있고, 광고비 그래프는 올라가 있다. 책상에는 식은 커피와 포스트잇이 있다.

화면 소품:

```text
월 광고비 8천
이번 주 매출?
대행사 미팅 11시
```

대사:

```text
서진: 광고비는 더 썼는데...
     매출은 왜 떨어졌지?
```

감정:

불길함. 평소처럼 시작한 월요일이지만, 숫자가 이미 이상하다.

## 페이지 2. 첫 번째 압박, 대행사 보고서

이미지 파일:

```text
assets/webtoon-page-02-text.png
```

장면:

화상회의 화면. 대행사는 주간 리포트 슬라이드를 띄우고 있다. 슬라이드에는 `ROAS는 방어 중`이라는 문구가 보인다. 서진은 회의 화면 옆에 띄워둔 매출 그래프를 보고 있다.

대행사:

```text
대행사: 전체 ROAS는 아직 안정적입니다.
       다음 주엔 소재를 조금 더 교체해보겠습니다.
```

서진 속마음:

```text
서진: 안정적인데 왜 매출은 꺾였지?
```

감정:

숫자는 괜찮다고 말하는데, CEO의 감각은 전혀 안심되지 않는다.

## 페이지 3. 두 번째 압박, 모두 광고 문제처럼 말한다

이미지 파일:

```text
assets/webtoon-page-03-text.png
```

장면:

회의실. 유나는 광고 관리자 화면을 크게 띄운다. 태오는 고객 문의 화면을 보다가 말을 삼킨다. 화면 한쪽에 `정기배송 해지` 메일 제목이 작게 보이지만 아무도 주목하지 않는다. 민재는 리뷰 파일을 들고 있지만 회의의 중심은 광고 성과표다. 모두가 자연스럽게 “광고 소재 문제”로 몰아간다.

대사:

```text
유나: 신규 소재 효율이 조금 애매하긴 해요.

대행사: 소재 피로도가 온 것 같습니다.

민재: 상세페이지도 한번 손보면 어떨까요?
```

서진:

```text
서진: 그럼 광고 소재를 갈면 해결되는 건가요?
```

감정:

모두가 그럴듯한 답을 말하지만, 어딘가 찜찜하다. 진짜 단서는 배경에 있지만 아직 아무도 잡지 못한다.

## 페이지 10. 두 번째 발견, 고객의 말이 원인이 된다

이미지 파일:

```text
assets/webtoon-page-10-text.png
```

장면:

댓글과 리뷰 문장들이 크게 확대된다. 옆에는 광고 카피가 떠 있다. 고객의 실제 말과 광고 메시지가 어긋나 있다.

고객 반응:

```text
생각보다 달아요.
정기배송 해지가 어려워요.
광고랑 느낌이 달라요.
```

광고 카피:

```text
매일 먹어도 부담 없는 맛
```

하로:

```text
하로: 광고는 “부담 없는 맛”을 말하지만,
     신규 고객 리뷰는 “생각보다 달다”에 몰려 있습니다.
```

유나:

```text
유나: 그러면 소재 문제가 아니라
     기대치가 어긋난 거네요.
```

감정:

문제가 광고 효율 하나가 아니라 고객 기대치와 연결되어 있음을 발견한다.
