# 대행사 시나리오 캐릭터 시트

## 전체 스타일

```text
장르: 현대 오피스 웹툰
톤: 현실적, 빠른 업무 리듬, 세련됨, 약간의 따뜻함
선: 깔끔한 라인, 과장 적은 표정
색감: 화이트/네이비/민트 포인트 + 하로의 라임 그린
배경: 마케팅 대행사 사무실, 회의실, 메신저 화면, 광고 관리자, 웹 보고서 UI
```

목표:

- 과장된 개그보다 B2B PT에 넣어도 어색하지 않은 비즈니스 웹툰
- 독자가 “우리 대행사 얘기다”라고 느끼게 한다.
- 하로는 `../advertiser/assets/haro-ui-reference-v1.png`의 깔끔한 SaaS UI 느낌을 따른다.
- 하로 아이콘은 `../advertiser/assets/haro-icon-reference-v2.png`를 기준으로 한다.
- 라임 그린 원형 구체, 귀여운 타원형 눈 두 개, 광택감 있는 말랑한 표면, 단순한 표정 변형을 유지한다.

## 지윤

역할:

```text
마케팅 팀장
월 1억 원 광고 예산을 4명 팀으로 운영하며, 광고주 보고와 팀 운영의 최종 책임자
```

외형:

- 30대 중반
- 단정한 셔츠나 재킷, 바쁜 업무 때문에 소매를 걷은 모습
- 노트북, 캘린더, 메신저 알림을 동시에 본다.
- 초반에는 눈 밑 그림자와 긴장된 어깨
- 후반에는 팀원들을 지휘하는 차분한 표정

성격:

- 일 잘하고 책임감이 강하다.
- 팀원들을 몰아붙이기보다 자신이 더 떠안는 타입.
- 반복 업무가 줄어들면 전략과 광고주 설득에 집중하고 싶어한다.

대표 대사:

```text
이게 정말 내가 해야 하는 일인가?

보고서 말고, 광고주가 바로 결정할 수 있는 형태로 보여줘.

하로가 제 팀원이 아니라, 제 팀이 된 것 같아요.
```

시각 키워드:

```text
리포트에 갇힌 팀장 -> 광고주 액션을 제안하는 운영 리더
```

## 민서

역할:

```text
팀원
매체별 성과 리포트 취합과 광고주 보고서 초안을 주로 맡는다.
```

외형:

- 20대 후반~30대 초반
- 노트북 화면에 엑셀 파일 여러 개가 떠 있음
- 포스트잇, 파일명, 피벗 테이블, 캡처 이미지가 주변에 많다.
- 초반에는 지친 표정, 후반에는 분석 코멘트를 쓰는 모습

성격:

- 꼼꼼하지만 반복 취합에 시간이 너무 많이 들어간다.
- 광고주별 보고 기준을 잘 기억하지만 개인 머릿속에 쌓여 있다.
- 하로를 통해 취합 업무에서 벗어나 성과 변화 해석에 집중하게 된다.

대표 대사:

```text
컬럼명이 매체마다 다 달라요.

하로야, A광고주 이번 주 리포트야.
지난주 대비 성과 변화랑 코멘트까지 정리해줘.
```

시각 키워드:

```text
엑셀 취합 담당자 -> 광고주 성과 해석 담당자
```

## 도현

역할:

```text
팀원
광고 소재 요청, 디자이너/영상 담당자 커뮤니케이션, 소재 피드백을 맡는다.
```

외형:

- 30대 초반
- 캐주얼 셔츠, 태블릿이나 디자인 레퍼런스 보드
- 광고 시안, 카피, 수정 요청 메시지를 자주 본다.

성격:

- 감각이 좋지만 요청서와 피드백 정리에 시간을 많이 쓴다.
- 광고주가 싫어하는 표현과 좋아하는 톤을 기억하고 있다.
- 하로와 함께 소재 요청서, 광고물 초안, 영상 콘티를 빠르게 만든다.

대표 대사:

```text
광고주는 숫자 근거 없는 과장 표현을 싫어해요.

하로야, 후기 기반 메시지로 소재 요청서 만들어줘.
```

시각 키워드:

```text
피드백 전달자 -> 크리에이티브 운영자
```

## 수아

역할:

```text
팀원
매체 운영, 신규 매체 발굴, 매체 담당자 커뮤니케이션을 맡는다.
```

외형:

- 20대 후반
- 메신저, 메일, 체크리스트 화면을 빠르게 오간다.
- 이어폰, 캘린더, 매체 규격표가 자주 등장한다.

성격:

- 실행력이 좋고 커뮤니케이션이 빠르다.
- 하지만 매체별 세팅 조건과 온보딩 히스토리가 흩어져 있어 늘 바쁘다.
- 하로를 통해 메일 초안, 체크리스트, 진행 상황 인수인계를 자동화한다.

대표 대사:

```text
계약서는 끝났고, 픽셀 설치 확인이 아직이에요.

하로야, C매체 온보딩 메일 써줘.
```

시각 키워드:

```text
메신저에 붙잡힌 운영자 -> 매체 확장 담당자
```

## 광고주 담당자

역할:

```text
대행사의 주요 광고주
보고서를 받지만, 결국 알고 싶은 것은 다음 주 실행안인 사람
```

외형:

- 30대~40대
- 화상회의 화면이나 링크 검토 화면으로 등장
- 숫자보다 액션 플랜을 유심히 본다.

성격:

- 보고서 양보다 판단 가능한 요약을 원한다.
- 대행사가 먼저 질문하고 제안할 때 신뢰한다.

대표 대사:

```text
이번 주에 그래서 뭘 바꾸면 되나요?

이 링크 하나면 내부 공유도 되겠네요.
```

시각 키워드:

```text
보고서 수신자 -> 액션 플랜에 동의하는 의사결정자
```

## 하로

역할:

```text
AI 코워크 솔루션
마케팅 팀의 자료, 맥락, 실행 규칙을 배우고 팀의 공용 기억처럼 작동한다.
```

시각 표현:

- 라임 그린 원형 AI 아이콘
- 귀여운 작은 타원형 눈 두 개
- 광택감 있는 말랑한 구체 질감
- 화면 속 UI 아이콘, 말풍선, 대시보드 보조 배지로 등장
- 사람형 로봇이 아니라 “작고 똑똑한 동그라미 조수”

하로의 톤:

- 바로 과장하지 않고 먼저 구조를 확인한다.
- 사용자의 피드백을 규칙으로 저장한다.
- 자료를 광고주가 이해할 수 있는 형태로 포장한다.
- 팀원이 빠져도 업무 맥락을 이어준다.

대표 대사:

```text
바로 자동화하기 전에, 먼저 이 일이 어떤 구조인지 확인해볼게요.

이 광고주는 액션 플랜을 먼저 보는 형식을 선호합니다.

민서님이 쓰던 보고서 기준으로 이어서 만들겠습니다.
```

시각 키워드:

```text
팀의 공용 기억이 되는 귀여운 원형 AI 파트너
```

## 배경/소품

### 대행사 사무실

- 여러 모니터
- 엑셀 파일, 광고 관리자, 메신저 알림
- 일정표와 광고주별 폴더
- 피곤하지만 빠르게 움직이는 팀 분위기

### 지윤의 책상

- 식은 커피
- `캠페인_성과_통합_최종_진짜최종_v7.xlsx`
- 광고주 미팅 일정
- 매체 리포트 파일 묶음

### 하로 보고서 UI

구성:

```text
다음 주 실행안
이번 주 성과 요약
매체별 변화
소재별 인사이트
광고주 공유 코멘트
검토 링크
```

시각:

- `../advertiser/assets/haro-ui-reference-v1.png`의 깔끔한 SaaS 대시보드 감각
- 웹페이지형 보고서처럼 보이는 공유 링크 화면
- 숫자보다 액션과 코멘트가 먼저 보이는 구조
- 광고주가 바로 내부 공유할 수 있는 정돈된 레이아웃
