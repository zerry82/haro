## 이미지 저장 규칙

생성 이미지는 반드시 `assets/` 폴더에 저장한다.

광고주용에서 확정한 하로 UI/아이콘 레퍼런스는 다음을 공통 기준으로 사용한다.

| 레퍼런스 | 내용 |
| --- | --- |
| [../advertiser/assets/haro-ui-reference-v1.png](../advertiser/assets/haro-ui-reference-v1.png) | 하로의 깔끔한 SaaS UI 톤 |
| [../advertiser/assets/haro-icon-reference-v2.png](../advertiser/assets/haro-icon-reference-v2.png) | 하로의 라임 그린 원형 아이콘 |

하로 아이콘은 다음처럼 설정한다.

```text
라임 그린 원형 아이콘
귀여운 타원형 눈 두 개
광택감 있는 말랑한 구체
단순하고 기억하기 쉬운 AI 파트너
특정 캐릭터를 그대로 복제하지 않는 오리지널 디자인
```

이후 생성물은 다음 이름부터 사용한다.

```text
assets/webtoon-page-01-text.png
assets/webtoon-page-02-text.png
assets/webtoon-page-03-text.png
...
assets/webtoon-page-18-text.png
```

웹툰은 총 18페이지로 제작한다.

```text
스토리보드 1컷 = 웹툰 1페이지
```

## 톤

- 현실적인 마케팅 대행사/운영팀 내부 이야기
- 팀장이 겪는 리포트, 소재 요청, 광고주 대응, 인수인계 압박에서 시작
- 하로는 한 번에 모든 것을 해결하는 마법 도구가 아니라, 자료와 피드백을 배우며 팀의 공용 기억이 되는 코워커로 표현
- 결과물은 광고주가 바로 볼 수 있는 웹페이지형 보고서와 검토 링크로 보여준다.
- 마지막에는 “대행사가 보고서를 만드는 팀”에서 “광고주에게 다음 액션을 제안하는 팀”으로 바뀌는 변화를 보여준다.
