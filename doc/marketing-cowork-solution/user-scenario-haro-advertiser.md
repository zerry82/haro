# 사용자 시나리오: 광고주가 하로를 쓰는 경우

## 등장인물

| 이름 | 역할 |
| --- | --- |
| 서진 | D2C 브랜드의 CEO. 매출, 광고비, 고객 반응, 상품 개선을 모두 챙겨야 한다. |
| 유나 | 마케팅 담당자. 광고 운영, 콘텐츠, 이벤트, 리포트를 맡는다. |
| 태오 | CX 담당자. 고객 문의, 클레임, 후기 대응을 맡는다. |
| 민재 | 상품기획 담당자. 리뷰와 고객 반응을 바탕으로 상품 개선안을 만든다. |
| 하로 | 브랜드 내부의 마케팅/고객반응/상품개선 업무를 함께 처리하는 AI 코워크 솔루션. |

이 문서에서 대화는 다음처럼 표기한다.

```text
하로: AI 솔루션이 하는 말
서진: CEO가 하는 말
유나/태오/민재: 각 담당자가 하는 말
```

## 1. 광고비는 쓰는데, 왜 팔리는지 모르겠다

서진은 작은 D2C 브랜드를 운영하고 있었다.

건강 간편식 브랜드였다.

제품은 나쁘지 않았다. 재구매율도 괜찮았다. 하지만 매출은 매달 들쭉날쭉했고, 광고비는 점점 커졌다.

월 광고비는 8천만 원까지 올라왔다.

문제는 돈을 쓰고 있다는 사실보다, 무엇이 진짜로 작동하는지 선명하게 보이지 않는다는 점이었다.

Meta 광고 관리자에는 숫자가 있었다.

네이버 스마트스토어에는 리뷰가 있었다.

인스타그램에는 댓글이 있었다.

카카오 채널에는 문의가 있었다.

고객센터 메일에는 클레임이 있었다.

광고 대행사는 매주 보고서를 보냈다.

하지만 서진이 알고 싶은 것은 보고서에 잘 나오지 않았다.

```text
서진: 사람들이 왜 사는 거지?
     왜 안 사는 거지?
     광고는 뭐가 먹히고, 제품은 어디서 불만이 생기는 거지?
```

유나는 광고 성과를 봤다.

태오는 고객 문의를 봤다.

민재는 상품 리뷰를 봤다.

각자 열심히 보고 있었지만, 서진에게는 하나로 연결된 그림이 필요했다.

## 2. CEO가 하로에 가입했다

서진은 하로에 가입했다.

첫 화면에는 이렇게 적혀 있었다.

```text
하로: 아무거나 힘들었던 것부터 자동화해보세요.
```

서진은 잠깐 고민하다가 적었다.

```text
서진: 광고비를 꽤 쓰고 있는데,
     고객 반응이랑 광고 성과랑 상품 후기가 따로 놀아요.
     내가 매주 볼 수 있게 하나로 정리하고 싶어요.
```

하로가 답했다.

```text
하로: 좋습니다.
     광고 성과, 소셜 댓글, 상품 후기, 고객 문의/클레임을 한곳에서 보려는 거네요.
     먼저 현재 자료가 어디에 있는지 확인할게요.
```

## 3. 하로가 물은 것

하로는 CEO에게 복잡한 대시보드 세팅을 요구하지 않았다.

대신 하나씩 물었다.

```text
하로: 광고 성과는 어디에서 확인하시나요?

서진: Meta랑 네이버 검색광고요.

하로: 고객 반응은 어디에 흩어져 있나요?

서진: 인스타 댓글, 유튜브 댓글, 네이버 리뷰, 자사몰 리뷰,
     카카오 채널 문의, 고객센터 메일이요.

하로: 매주 CEO님이 꼭 알고 싶은 질문은 무엇인가요?

서진: 이번 주에 왜 팔렸는지, 왜 안 팔렸는지.
     불만이 늘고 있는지.
     어떤 메시지를 더 밀어야 하는지.
     상품을 고쳐야 할 부분이 있는지.
```

하로는 말했다.

```text
하로: 그러면 첫 자동화는 “CEO 주간 브랜드 상황판”으로 만들겠습니다.
     광고 성과와 고객 반응을 한 페이지에서 보게 해볼게요.
```

## 4. 첫 자료는 대충 던졌다

서진은 자료를 완벽히 준비하지 못했다.

Meta 광고 성과 CSV.

네이버 검색광고 리포트.

스마트스토어 리뷰 엑셀.

자사몰 리뷰 CSV.

고객센터 메일 일부를 export한 파일.

인스타그램 댓글 캡처 몇 장.

정리되지 않은 파일들이었다.

서진은 미안하다는 듯 말했다.

```text
서진: 일단 있는 것만 올렸어요.
     형식이 좀 제각각이에요.
```

하로가 답했다.

```text
하로: 괜찮습니다.
     처음에는 완벽한 자료보다 실제로 쓰시는 자료가 더 좋습니다.
     제가 구조를 보고, 반복 가능한 형태로 정리해볼게요.
```

## 5. 하로의 첫 번째 상황판

잠시 뒤 하로가 첫 결과를 보여줬다.

```text
하로: 이번 주 브랜드 상황판 초안을 만들었습니다.
```

상단에는 숫자가 있었다.

```text
이번 주 매출: 184,000,000원
광고비: 42,000,000원
ROAS: 438%
신규 구매자: 3,420명
재구매율: 21.4%
평균 리뷰 평점: 4.62
클레임 메일: 전주 대비 18% 증가
```

하지만 서진의 눈에 들어온 것은 숫자보다 그 아래였다.

```text
이번 주 고객 반응 요약

긍정 반응:
- “아침에 먹기 편하다”
- “단백질 함량이 마음에 든다”
- “배송이 빨랐다”

부정 반응:
- “생각보다 달다”
- “포장이 뜯기 어렵다”
- “정기배송 해지가 불편하다”

구매를 만든 메시지:
- 바쁜 아침 대체
- 부담 없는 단백질 보충
- 냉장고에 쟁여두는 간편식

구매를 막은 요인:
- 맛이 달다는 우려
- 정기배송 조건 불안
- 가격 대비 양에 대한 의문
```

서진은 화면을 오래 봤다.

처음으로 광고 성과와 고객 목소리가 같은 페이지에 있었다.

## 6. CEO의 첫 피드백

서진은 바로 말했다.

```text
서진: 숫자는 좋은데, 나는 “이번 주에 뭘 해야 하는지”가 먼저 보였으면 좋겠어요.
     액션 중심으로 바꿔줘요.
```

하로가 답했다.

```text
하로: 알겠습니다.
     CEO용 화면은 지표보다 의사결정이 먼저 보이도록 바꾸겠습니다.
```

다시 생성된 상황판의 맨 위에는 숫자가 아니라 실행안이 있었다.

```text
이번 주 CEO 액션 제안

1. “덜 단 맛” 메시지를 광고 소재에 추가
2. 정기배송 해지 방법을 상세페이지 상단 FAQ로 이동
3. 포장 뜯기 어려움 리뷰가 늘고 있어 패키지 개선 검토
4. Meta 광고는 “아침 대체” 메시지 예산 20% 증액
5. 네이버 검색광고는 “단백질 간편식” 키워드 CPA 상승으로 입찰 조정
```

서진은 고개를 끄덕였다.

```text
서진: 이게 내가 보고 싶던 거예요.
```

## 7. 소셜 댓글이 광고 기획으로 이어졌다

며칠 뒤 유나가 하로에게 물었다.

```text
유나: 하로야, 이번 주 인스타 댓글에서 광고 소재로 쓸 만한 반응 찾아줘.
```

하로는 댓글을 분류했다.

```text
하로: 반복적으로 나오는 표현은 세 가지입니다.

1. “아침에 챙겨 먹기 편하다”
2. “운동 후에 먹기 좋다”
3. “생각보다 달다”
```

하로는 이어서 제안했다.

```text
하로: 광고 소재는 두 방향으로 나눌 수 있습니다.

소재 A: 바쁜 아침 대체식
소재 B: 운동 후 단백질 보충

단맛 우려는 FAQ와 상세페이지에서 먼저 해소하는 편이 좋습니다.
```

유나는 말했다.

```text
유나: 그럼 댓글 기반으로 광고 카피 10개랑 이미지 방향 만들어줘.
```

하로는 카피와 이미지 방향을 만들었다.

```text
카피 예시:
- 아침을 거르는 대신, 30초면 충분한 한 끼
- 출근 전 냉장고에서 꺼내는 단백질 루틴
- 운동 후 부담 없이 채우는 간편 단백질
```

그중 세 가지는 실제 광고물 초안으로 만들어졌다.

유나는 더 이상 감으로 소재를 만들지 않았다.

고객 댓글이 바로 광고 아이디어가 되었다.

## 8. 상품 후기가 상품 개선 회의로 이어졌다

민재는 매주 리뷰를 보긴 했지만, 늘 일부만 봤다.

리뷰는 많았고, 반복되는 불만을 정리하는 데 시간이 오래 걸렸다.

어느 날 민재가 하로에게 물었다.

```text
민재: 최근 한 달 상품 후기에서 반복되는 불만만 뽑아줘.
     진짜 상품 개선에 반영할 만한 것 위주로.
```

하로는 리뷰를 읽고 분류했다.

```text
하로: 최근 한 달 리뷰 1,842건 기준 반복 불만은 다음과 같습니다.

1. 맛이 예상보다 달다 - 214건
2. 포장이 잘 안 뜯긴다 - 136건
3. 정기배송 변경이 어렵다 - 92건
4. 가격 대비 양이 적다 - 88건
5. 배송 박스가 과하다 - 47건
```

민재가 물었다.

```text
민재: 이 중에서 상품 자체를 바꿔야 하는 거랑,
     상세페이지 설명으로 해결 가능한 거 나눠줘.
```

하로가 답했다.

```text
하로: 상품 개선 후보:
     - 단맛 조정
     - 포장 절취선 개선
     - 배송 박스 크기 최적화

상세페이지/커뮤니케이션으로 해결 가능한 항목:
     - 가격 대비 양 설명
     - 정기배송 변경/해지 안내
```

이 내용은 그대로 상품 개선 회의 안건이 됐다.

민재는 말했다.

```text
민재: 이제 리뷰를 그냥 보는 게 아니라, 제품 로드맵으로 바꿀 수 있겠네요.
```

## 9. 메일 클레임이 위험 신호가 됐다

태오는 고객센터 메일을 매일 봤다.

하지만 메일함은 늘 바빴고, 위험 신호는 늦게 보였다.

어느 화요일, 하로가 먼저 알림을 보냈다.

```text
하로: 이번 주 클레임 메일에서 “정기배송 해지” 관련 불만이 전주 대비 41% 증가했습니다.
     특히 “해지 버튼을 찾기 어렵다”는 표현이 반복됩니다.
```

태오가 물었다.

```text
태오: 심각한 건가?
```

하로가 답했다.

```text
하로: 현재는 CS 이슈지만,
     방치하면 리뷰 평점과 광고 효율에 영향을 줄 가능성이 있습니다.

권장 조치:
1. 정기배송 해지 안내 메일 템플릿 수정
2. 마이페이지 FAQ 위치 조정
3. 상세페이지 하단에 정기배송 조건 명확히 표시
4. 광고 소재에서 “정기배송 필수”처럼 오해될 표현 제거
```

태오는 바로 서진에게 공유했다.

서진은 그날 오후 제품팀과 CX팀을 함께 불렀다.

이전에는 클레임이 쌓이고 리뷰 평점이 떨어진 뒤에야 움직였다.

이제는 고객 불만이 광고 성과에 영향을 주기 전에 감지됐다.

## 10. 광고 성과와 고객 반응이 한 화면에 붙었다

한 달 뒤, 서진은 매주 월요일 아침마다 하로의 상황판을 열었다.

화면은 네 영역으로 나뉘어 있었다.

```text
1. 이번 주 CEO 액션
2. 광고 성과 변화
3. 고객 반응 변화
4. 상품/CS 개선 신호
```

서진은 더 이상 광고 대행사 보고서, 스마트스토어 리뷰, 인스타 댓글, 고객센터 메일을 따로 보지 않았다.

하로가 먼저 연결했다.

```text
하로: 이번 주 ROAS 하락은 광고 소재 피로도보다
     “맛이 달다”는 리뷰 증가와 관련이 있어 보입니다.

     특히 신규 고객의 첫 구매 전환율이 떨어졌고,
     상세페이지 체류 시간은 늘었지만 구매 전환은 줄었습니다.

     상세페이지 상단에 “단맛 정도” 설명을 추가하고,
     광고 소재에서는 “가볍게 먹는 단백질 간편식” 메시지를 테스트하는 것을 권장합니다.
```

서진은 유나, 태오, 민재를 불렀다.

예전 같으면 각자 다른 자료를 들고 왔을 것이다.

이제는 같은 화면을 보고 이야기했다.

## 11. CEO가 슈퍼바이저가 됐다

서진의 역할도 바뀌었다.

예전에는 서진이 직접 자료를 모으고, 담당자에게 물어보고, 보고서를 비교해야 했다.

이제 서진은 하로에게 질문했다.

```text
서진: 이번 주에 내가 꼭 봐야 할 위험 신호만 말해줘.
```

하로가 답했다.

```text
하로: 세 가지입니다.

1. 정기배송 해지 불만 증가
2. “달다”는 리뷰가 신규 구매 전환율에 영향
3. Meta 신규 소재 피로도 상승
```

서진은 다시 물었다.

```text
서진: 그럼 이번 주 우선순위는?
```

하로가 정리했다.

```text
하로: 1순위는 정기배송 해지 안내 개선입니다.
     클레임, 리뷰, 광고 전환율 모두에 영향을 줍니다.

     2순위는 단맛 관련 커뮤니케이션 정리입니다.
     상품 개선은 시간이 걸리므로, 먼저 상세페이지와 광고 문구를 수정하는 것이 좋습니다.

     3순위는 Meta 소재 교체입니다.
     기존 소재는 유지하되, 댓글 기반 신규 카피 3종을 테스트하세요.
```

서진은 이제 모든 일을 직접 들여다보는 사람이 아니었다.

하로가 팀의 자료를 읽고, 변화를 감지하고, 실행안을 정리했다.

서진은 우선순위를 정하고 승인했다.

CEO는 실무자가 아니라 슈퍼바이저가 되었다.

## 12. 대행사와의 관계도 달라졌다

서진은 광고 대행사를 끊지 않았다.

하지만 대행사를 대하는 방식이 달라졌다.

예전에는 대행사가 보고서를 주면 서진이 해석해야 했다.

이제는 하로가 먼저 검토했다.

```text
서진: 하로야, 대행사 주간 보고서 봐줘.
     빠진 내용이 있는지, 우리가 물어봐야 할 것 정리해줘.
```

하로가 답했다.

```text
하로: 보고서에는 ROAS 개선이 강조되어 있지만,
     신규 고객 전환율 하락과 리뷰 불만 증가는 언급되어 있지 않습니다.

     대행사에 물어볼 질문:
     1. 신규 고객 전환율 하락 원인을 어떻게 보고 있는지
     2. “달다”는 리뷰 증가가 소재 메시지와 충돌하는지
     3. 다음 주 소재 테스트 계획에 댓글 기반 카피를 반영할 수 있는지
```

서진은 그대로 회의에 들어갔다.

대행사와의 대화가 달라졌다.

서진은 더 이상 보고서를 받는 사람이 아니었다.

질문을 준비한 광고주였다.

## 13. 이 시나리오가 보여주는 것

광고주가 겪는 페인포인트는 대행사와 다르다.

대행사는 많은 광고주를 효율적으로 운영해야 한다.

광고주는 자기 브랜드의 성과와 고객 반응을 깊게 이해해야 한다.

진짜 문제는 다음이다.

- 광고 성과, 리뷰, 댓글, CS 메일이 서로 다른 곳에 흩어져 있다.
- 숫자는 보이지만 “왜 팔리는지/왜 안 팔리는지”는 잘 보이지 않는다.
- 고객 불만이 광고 효율, 리뷰 평점, 상품 개선과 연결되지 않는다.
- CEO는 실무 자료를 모두 볼 시간이 없지만, 중요한 신호를 놓치면 안 된다.
- 마케팅 담당자, CX 담당자, 상품 담당자가 각자 다른 자료를 보고 일한다.
- 대행사 보고서만으로는 브랜드 내부의 고객 목소리까지 반영하기 어렵다.

하로의 접근은 다음이다.

- 광고 성과, 소셜 댓글, 상품 후기, CS 메일을 한곳으로 모은다.
- 반복되는 고객 반응을 분류한다.
- 광고 성과와 고객 반응을 연결한다.
- 클레임 증가 같은 위험 신호를 먼저 감지한다.
- CEO에게 숫자보다 액션 중심으로 보여준다.
- 담당자별 실행안으로 나눠준다.
- 광고주가 대행사와 더 똑똑하게 대화하도록 돕는다.

기대효과는 다음이다.

- CEO가 매주 브랜드 상황을 빠르게 파악한다.
- 광고 성과와 고객 반응이 한 화면에서 연결된다.
- 리뷰와 클레임이 상품 개선으로 이어진다.
- 소셜 댓글이 광고 소재 아이디어가 된다.
- 대행사 보고서를 더 잘 검토하고 질문할 수 있다.
- 고객 불만이 커지기 전에 대응할 수 있다.
- 마케팅, CX, 상품팀이 같은 화면을 보고 움직인다.

하로의 광고주 버전 가치는 다음 한 문장으로 정리할 수 있다.

```text
브랜드가 흩어진 광고 성과와 고객 목소리를 하나로 연결하고,
CEO가 액션 중심으로 의사결정할 수 있게 만드는
AI 브랜드 상황판이자 실행 파트너.
```
