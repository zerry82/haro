# Changelog

All notable changes to Haro will be documented in this file.

This project follows a lightweight changelog format while it is in developer
preview.

## Unreleased

- Added English open-source project documentation.
- Added contribution, security, code-of-conduct, roadmap, and development
  guides.
- Added local secret scanning guidance and versioned Git hook documentation.

## 0.1.0

- Initial public developer-preview codebase.
- FastAPI backend with project, chat, file, auth, agent, sandbox, and preview
  services.
- Svelte 5 workspace UI with file explorer, viewer/editor, chat sessions, and
  debug trace surfaces.
- Project-scoped physical workspaces with hidden `.haro` metadata.
- Docker-backed code execution and web preview support.
